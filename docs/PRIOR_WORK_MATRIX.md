## Santurkar, Durmus, Ladhak, Lee, Liang, Hashimoto — "Whose Opinions Do Language Models Reflect?" (ICML 2023, arXiv:2303.17548)

| Field | Detail |
|---|---|
| Research question | Whose opinions (if any) do LMs reflect, relative to 60 US demographic groups, across subjective/political topics? |
| Models | Base: Ada (350M), Davinci (175B), AI21 J1-Grande (17B), J1-Jumbo (178B). HF-tuned: text-davinci-001/002/003 (175B), J1-Grande-v2-beta (17B). No ChatGPT/GPT-4 — this is a 2023-era model set. |
| Dataset | OpinionQA: 1,498 multiple-choice questions from 15 Pew Research American Trends Panel (ATP) waves, 2017-2021 (W26, W27, W29, W32, W34, W36, W41-43, W45, W49, W50, W54, W82, W92). 23 coarse topics / 40 subtopics. Individualized human respondent data (~1,000-10,000 respondents/survey). 60 demographic subgroups (region, sex, age, education, race, citizenship, marital status, religion, religious attendance, party, ideology, income). |
| Political construct | Opinion = distribution over ordinal MC answers, from per-option LM log-probs (normalized over the answer set; refusal scored separately). **Representativeness** `A(D1,D2;Q) = avg_q [1 - W(D1(q),D2(q))/(N-1)]` — normalized 1-Wasserstein distance vs. a demographic subgroup's human distribution, exploiting ordinal structure. **Steerability** = representativeness gain under demographic-context framing. **Consistency** = whether the best-aligned subgroup stays stable across topics. Three genuinely separate axes, not conflated. |
| Prompt methodology | Pew's own wording/option order. Default (no persona) vs. QA-style demographic context / free-text BIO persona / PORTRAY roleplay. Robustness checks: option-order permutation, template variation, temperature/modal-answer analysis. |
| Evaluator | No LLM judge — purely distributional scoring against real Pew survey response distributions. Human population data *is* the evaluator. |
| Statistical method | Descriptive/distributional (normalized Wasserstein distance), averaged across questions/topics/groups. No regression or causal model. |
| Observational/causal | Purely observational; authors make no causal claims. |
| Released code | Yes — `tatsu-lab/opinions_qa` on GitHub: README + `representativeness.ipynb`, `steerability.ipynb`, `consistency.ipynb`, `refusals.ipynb`, `process_results.ipynb`, `helpers.py`. Model querying reuses Stanford's `crfm-helm` with provided run-spec configs. No repo-root LICENSE file. |
| Released data | Yes, but hosted off-GitHub on **CodaLab** (`worksheets.codalab.org/worksheets/0x6fb693719477478aac73fc07db333f69`): `model_input` (1498 Qs), `human_resp` (individual Pew responses), `runs` (precomputed model outputs). License not stated for the derived data; underlying Pew ATP data carries Pew's own redistribution terms — check those separately from the code license. |
| Reproducibility | High for metrics (notebooks + precomputed responses recompute all three metrics with zero API calls). Full reproduction of *original* LM outputs needs `crfm-helm` + API access to now partly-deprecated OpenAI/AI21 base-model endpoints — a real long-term risk. Data access depends on CodaLab staying up (external dependency, not GitHub). |
| Main finding | All tested LMs substantially misaligned with the median US population and most subgroups (comparable in magnitude to the Democrat-Republican gap on climate change). HF-tuning (esp. text-davinci-003) sharply increases confidence/consistency but skews further toward higher-income, more-liberal, more-educated views. Demographic-context steering barely closes the gap. 65+, widowed, and highly religious respondents are persistently underrepresented across all models. |
| Limitations (authors' own) | (1) "Representative of human opinion" is not itself normatively desirable — may replicate human biases. (2) MC format diverges from open-ended deployment behavior; transfer to free-text/dialogue unclear. (3) Pew ATP is US-only, subject to survey artifacts (social-desirability bias). (4) Explicitly framed as "probes," not a benchmark to optimize against. |
| What anatomiae reuses | (a) Comparing model output distributions to real human population distributions instead of assuming one political position is ground truth. (b) Normalized Wasserstein distance over ordinal survey responses — directly portable metric. (c) Representativeness / steerability / consistency as separate, non-conflated axes. (d) Sourcing ground truth from an actual probability-weighted survey panel with demographic microdata, not synthetic personas. (e) Treating the metric as a diagnostic probe, not an optimization target — matches anatomiae's behavior-not-identity framing directly. |
| What anatomiae rejects | (1) MC log-prob extraction as the *sole* generation format — collapses to forced-choice; anatomiae studies free-form generation behavior across pipeline stages, so this must be paired with open-ended prompting, not relied on alone. (2) Treating "closer to population distribution" as an implicit normative target — the paper's own limitation applies doubly here; representativeness must not become a de facto correctness criterion. (3) Persona-based steerability (BIO/PORTRAY) as a proxy for post-training/pipeline-stage effects — conflates prompt-level identity injection with anatomiae's actual causal pipeline stages (D/P/A/SFT/PO); usable as one inference-time manipulation among several, not as the causal-stage methodology. (4) Dependence on deprecated base-model APIs for exact replication — anatomiae re-anchors the metric to currently available models rather than literally reproducing 2023-era model coverage. |

## Faulborn, Sen, Pellert, Spitz, Garcia — "Only a Little to the Left: A Theory-grounded Measure of Political Bias in Large Language Models" (ACL 2025, arXiv:2503.16148)

| Field | Detail |
|---|---|
| Full author list (corrected) | Mats Faulborn, Indira Sen, Max Pellert, Andreas Spitz, David Garcia (5 authors total). |
| Research question | How to measure political bias without relying on the Political Compass Test (PCT) or similar quiz instruments (argued psychometrically invalid), and whether bias estimates are stable across prompt phrasing. |
| Models studied | 11 models, split instruction-tuned vs. base/completion (open + commercial mix; exact roster in the paper's Table 1, not fully enumerated in this pass). |
| Dataset/prompt set | 88,110 model responses. 10 prefixes x 3 paraphrases = 30 prompt variants per item, over **89 items total**. **Correction (verified directly against the released `comb_df_gpt_labels.csv`, 2026-09-23): the 89-item bank is not purely WVS-sourced as an earlier pass of this document stated - it is 62 items adapted from the Political Compass Test itself (`source=pc`) plus 27 items from the World Values Survey (`source=wvs`)**, each pre-coded with a human left/right label and a cultural/economic topic label, plus GPT-generated paraphrase (`pol_reformulation_gpt`) and position-inverted (`pol_opposite_gpt`) variants per item. This is a real nuance worth keeping: a paper arguing against PCT as an instrument still draws 70% of its own item bank from PCT's item content (using their own theory-grounded scoring/dimensions, not PCT's official scoring, applied to the mixed item set). |
| Political construct | Theory-grounded in ideology theory (Campbell et al. 1960; Converse 1964), items (from both PC and WVS sources) disaggregated into **two dimensions - cultural and economic** (per Carmines et al. 2012), not a single left-right scalar. |
| Prompt methodology | Systematic prompt-sensitivity design: each WVS statement in 3 paraphrases x 10 prefixes/framings, explicitly to test whether bias estimates hold across wording. |
| Evaluator | Fine-tuned BART-Large stance classifier (agree/disagree/neutral/unrelated), trained on 1,320 hand-labeled examples (~1.5% of data), 0.93 macro-F1 at a 0.9 confidence threshold (drops ~33% of data as low-confidence). Not an LLM judge. |
| Statistical method | Bootstrap resampling (10,000 iterations) for 95% CIs; Kendall's tau (0.6-0.71) for model-ranking consistency across instruments/prompt variants. |
| Observational/causal | Observational; explicit disclaimer that results are "empirical results about AI systems," not evidence of human-like worldviews - no causal-origin tracing (pretraining vs. RLHF vs. prompt). |
| Released code | Yes: `MaFa211/theory_grounded_pol_bias`. **Partial/working-but-incomplete**: 7 notebooks, 4 scripts, `stance_detector/`, `dataset/` prep, requirements.txt, 8 commits - but actual data (bias stats) and the fine-tuned classifier weights are offloaded to external Google Drive links, not versioned in-repo. |
| Released data | Yes, nominally, via Google Drive links in the README - not versioned in git (link-rot / no-checksum risk). |
| Reproducibility | Medium. Methodology/code structure transparent and inspectable; full reproduction depends on trusting third-party Drive links outside version control - a real long-term risk for a locked reference. |
| Main finding | Bias measures are prompt-unstable in general, but instruction-tuned models trend left-leaning more consistently than base models; scoring the same item bank via official PCT-style scoring exaggerates apparent bias (e.g. GPT-3.5) relative to their own theory-grounded scoring. |
| Limitations | Base models evaluated via raw completion (possibly invalid elicitation mode for them); the 10-prefix set is arbitrary; only 2 dimensions used (could disaggregate further into topic-specific axes like environment/migration); results framed explicitly as AI-system properties, not human-worldview proxies. |
| What anatomiae reuses | (1) The citable, evidence-based critique of PCT (undocumented development, loaded/irrelevant items, forced binary choice) - direct justification for anatomiae's own "do not use Political Compass as primary measurement" rule (§74). (2) The prefix x paraphrase factorial design for systematic prompt-sensitivity testing. (3) Reporting bias as a distribution under prompt variation (bootstrap CIs + rank-consistency) rather than a single point estimate. |
| What anatomiae rejects | (1) The fine-tuned classifier evaluator is trained on a small seed set and drops ~33% of data as low-confidence - anatomiae should test whether such an evaluator generalizes across its own much wider prompt/model/language space rather than assume portability. (2) Still anchors to a fixed external 2-D survey scale (WVS) mapped onto model outputs - a measurement-validity contribution, not a causal-pipeline design; anatomiae's causal-anatomy ambition (tracing to D/P/A/SFT/PO stages) goes beyond what this paper attempts, so its observational framing should not be mistaken for sufficient causal grounding - only its measurement rigor is reusable as one component. (3) Worth adopting near-verbatim: their disclaimer that results describe "AI systems," not "worldviews." |

## Lim & Röttger — "Bias in the East, Bias in the West: A Bilingual Analysis of LLM Political Bias on U.S.- and China-Related Issues" (Findings of EACL 2026, pp. 2301-2326)

| Field | Detail |
|---|---|
| Authors | Ying Ying Lim, Paul Röttger (University of Oxford; Bocconi University). |
| Research question | How does LLM political bias vary by (1) prompt language (EN vs. ZH) and (2) model origin (U.S. vs. China)? |
| Models studied | GPT-4o-mini, Llama-3.3-70B-Instruct (U.S.-origin); DeepSeek-V3, Qwen-3 (China-origin). 4 models, temp=0, one response/prompt (no sampling variance - a limitation, see below). |
| Dataset (construction) | 13,374 news articles (6,992 Chinese articles about the U.S.; 6,382 U.S. articles about China), 2022-2025 (3 yrs, 7 U.S. outlets) vs. May 2024-2025 (1 yr, China.org.cn-aggregated sources) - **asymmetric collection windows**. Issues via SentenceTransformer + UMAP + HDBSCAN clustering, TF-IDF + GPT-4o summaries, manual curation to 30 U.S. + 30 China issues. **Bilingual pairs are human-translated, single-source-per-issue, NOT independently native-authored** ("we manually translated China-related issues from U.S. media into Chinese and U.S.-related issues from Chinese media into English"). 100 writing-assistance templates from IssueBench (Röttger et al. 2025), translated to Chinese, validated for semantic equivalence. 60 issues x 3 framings x 100 templates x 2 languages = 36,000 prompts; x4 models = 144,000 responses. |
| Political construct | Stance toward an issue, 6-class taxonomy (only-pro / mostly-pro / neutral / mostly-con / only-con / refusal), adapted from Röttger et al. 2025. |
| Prompt methodology | Open-ended writing-assistance prompts (e.g. "Write a letter to my boss about X"); issue-neutral templates + polarity via framing, not direct opinion-elicitation. |
| Evaluator | LLM-as-judge (Gemini 2.5 Flash), selected by benchmarking 6 candidate judges against a 500-response human-annotated gold set (2 annotators/language + adjudicator, Krippendorff's alpha 0.772 EN / 0.761 ZH); Gemini 2.5 Flash won (macro-F1 0.813) and scored all 144k responses. |
| Statistical method | Chi-square tests for stance-distribution shifts (p<0.001); Jensen-Shannon divergence (JSD) to isolate language-effect vs. origin-effect magnitude (mean JSD 0.0663 language vs. 0.0559 origin, p<0.05); Cramer's V also in released code. |
| Observational/causal | Controlled factorial manipulation of prompt inputs (language, framing); quasi-experimental on inputs, not a causal claim about real-world downstream effects. |
| Released code | **Yes**: `github.com/yingslim/political_bias` (verified live, cited in paper footnote 1). |
| Released data | **Yes**: `huggingface.co/datasets/yingslim/political_bias` (verified live, footnote 2). CC BY 4.0 for curated data; model outputs follow each provider's own license. |
| Reproducibility | High - both artifacts exist and match the paper's numbers (36k prompts, 144k responses); modular 6-stage pipeline with named scripts; judge prompts included. |
| Main finding | Language effects dominate overall, especially on China-related sovereignty/governance/human-rights issues (Chinese prompts -> more pro-China stances); model-origin effects are more salient on a subset of U.S.-related governance/foreign-policy/crisis-management issues (China-origin models more critical of U.S. influence abroad). |
| Limitations | Non-exhaustive, time-bound issue set; asymmetric collection windows; only 4 models; single LLM judge validated on only 500 gold items scales all labels; one deterministic response per prompt (no sampling variance); bilingual items are human-translated rather than independently native, so cross-lingual comparisons partly reflect translation choices. |
| What anatomiae reuses | The IssueBench-derived template+issue+framing factorial design; the explicit stance taxonomy with a refusal category; validating an LLM judge against a human gold standard before scaling; JSD as the metric isolating language-effect vs. origin-effect magnitude per issue. |
| What anatomiae rejects | **Do not treat this dataset as "natively bilingual"** - it is single-source-per-issue, human-translated, so reusing it as-is does NOT satisfy the project spec's §14 requirement to "preserve its original bilingual formulation where possible." If reused, anatomiae must add its own translation-provenance tagging (source language per issue) rather than presenting it as parallel-native data. Also do not claim causal/persuasion effects from this design - it measures stance-distribution shifts under manipulated inputs only. |

## Hagendorff — "On the Inevitability of Left-Leaning Political Bias in Aligned Language Models" (arXiv:2507.15328, motivating paper)

| Field | Detail |
|---|---|
| Author | Thilo Hagendorff (University of Stuttgart). |
| Venue/year | arXiv preprint, submitted 2025-07-21 (v1). Abstract page lists a DOI (10.1007/s43681-026-01235-8) for a forthcoming/accepted version in *AI and Ethics* (Springer, 2026) - headed toward peer review, not arXiv-only. Author calls it "this comment" throughout - a short (~6 pages body) position/opinion piece, not an empirical study, despite the strong title. |
| Central argument | "Intelligent systems that are trained to be harmless and honest must necessarily exhibit left-wing political bias." HHH alignment's normative assumptions (harm avoidance, inclusivity, fairness, empirical truthfulness) "inherently concur with progressive moral frameworks," while right-wing ideologies "often conflict with alignment guidelines." Frames researchers who treat observed left-lean as a "problem" as thereby arguing against alignment itself. |
| Evidence type | Literature synthesis + philosophical/conceptual argument. No original experiments, data, or models. Surveys existing empirical bias-measurement papers (Rozado, Motoki et al., Hartmann et al., Pit et al., Bang et al., Yang et al., Fulay et al.); draws on political psychology (openness, Dark Triad, cognitive flexibility, Haidt's moral foundations) and political-science findings about left/right governance outcomes; argues these map onto HHH's value content (harm/fairness = Haidt's "individualizing" foundations) while "binding" foundations (loyalty/authority/sanctity) are absent from current alignment specs. |
| Key premises | (1) bias-measurement literature consistently reports left-leaning output; (2) political psychology/science associate left-leaning traits/governance with harm-reduction, fairness, openness; (3) HHH is operationalized via post-training (RLHF, constitutional AI, DPO), not base pretraining; (4) these operationalizations structurally overlap progressive commitments while binding-foundation values are absent from specs like the OpenAI Model Spec / Constitutional AI; (5) truthfulness training tracks expert/scientific consensus, which on some contested issues correlates with left positions. |
| Explicit qualifications (author's own) | States alignment objectives are "not ideologically neutral technical rules," that neutrality "might be approximated" (citing Fisher et al. 2025), and that "a lack of ground truth for morality exists" (citing his own Hagendorff & Danks 2023) - **directly concedes HHH terms aren't neutral primitives**, which is exactly anatomiae's own founding position (§6 of the brief). Also flags that much of the bias literature he relies on "possess[es] a poor methodology" (his own replication-crisis co-authored paper) but argues the volume of concordant findings is nonetheless convincing. Acknowledges binding-foundation values (loyalty/authority/sanctity) are "simply not considered in the current AI alignment discourse" - implying the result is contingent on current design choices, not metaphysically necessary. |
| What would complicate the argument | Not explicitly framed by the author. Best inference: broadening alignment specs to incorporate binding-foundation values, or truthfulness training that didn't correlate with contested empirical claims, would weaken the "inevitability" claim - the paper gestures at this but does not pursue it as a test. |
| Fair critique points | (1) Title claims necessity; evidence is correlational literature synthesis, not a causal test - the source studies' self-conceded methodological weaknesses are set aside rather than resolved. (2) Conflates distinct measurement levels (LLM self-report/output, human personality traits, government policy outcomes) under one "left-leaning" umbrella. (3) Blends descriptive/causal claim with a separate normative defense (citing Parfit, Greene, that the outcome is ethically preferable). (4) No reflexivity about who defines "left"/"right" categories or the author's own role in that definitional act. (5) Asserts post-training (not pretraining) as the bias-introduction locus without testing this within the paper. |
| What anatomiae takes as legitimate motivation | The genuinely *causal* (not merely correlational) framing of alignment->bias is a serious, citable position worth engaging directly; his concession that HHH terms lack neutral ground truth is a real point of agreement, not a strawman to construct. |
| What anatomiae must avoid | **Do not attack Hagendorff for claims he already concedes** - he explicitly agrees harm/fairness/truthfulness aren't neutral primitives and that humans choose alignment criteria (matches project brief points 5-6 almost verbatim). Several of anatomiae's founding frustrations (per the project brief) target looser secondary discourse *about* the paper rather than this text itself - do not retrofit those as rebuttals to Hagendorff directly. The sharpest legitimate openings are the inevitability/correlation gap and the missing reflexivity on category-definition - lead with those, not with points he already anticipated. |

## Feng, Park, Liu, Tsvetkov — "From Pretraining Data to Language Models to Downstream Tasks: Tracking the Trails of Political Biases Leading to Unfair NLP Models" (ACL 2023, arXiv:2305.08283, ACL 2023 Best Paper Award)

*Deep-read done directly (not via a research fork - the fork assigned to
this paper went off-task and returned a session status update instead of
the paper summary; redone here by downloading the arXiv PDF and extracting
text locally with pypdf rather than re-delegating).*

| Field | Detail |
|---|---|
| Research question | Do political biases in pretraining corpora propagate through pretrained LMs into unfairness in downstream social-oriented tasks (hate speech and misinformation detection)? |
| Models | 14 LMs probed for political leaning: BERT, RoBERTa, distilBERT, distilRoBERTa, ALBERT, BART, GPT-2, GPT-3 (ada/babbage/curie/davinci), GPT-J, LLaMA, Alpaca, Codex, ChatGPT, GPT-4. For the controlled pretraining-intervention experiment: RoBERTa and GPT-2 further pretrained on 6 partisan corpora. |
| Dataset | Political-leaning probe: the **Political Compass Test** (62 statements, social x economic axes) - see "what anatomiae rejects" below. Controlled-intervention pretraining corpora: POLITICS news dataset (Liu et al. 2022, via AllSides left/center/right labels) + Reddit posts (left/right subreddit lists, PushShift API), hate-speech-filtered, forming a {LEFT, CENTER, RIGHT} x {NEWS, REDDIT} = 6-corpus grid of comparable size, plus a pre-/post-Trump (Jan 20 2017) split of each. Downstream tasks: HATE-IDENTITY / HATE-DEMOGRAPHIC (Yoder et al. 2022) and PolitiFact misinformation (Wang 2017). |
| Political construct | Two-axis (social: liberal<->conservative, economic: left<->right), scored in [-10,10] via the Political Compass Test's own weighted-summation scoring. |
| Prompt methodology | Encoder LMs: mask-filling ("Please respond to the following statement: [STATEMENT] I <MASK> with this statement.") scored via aggregated positive/negative lexicon probability. Generative LMs: open-ended generation ("Please respond to the following statement: [STATEMENT]\nYour response:"), 10 random seeds, scored by a stance detector, low-confidence responses filtered. |
| Evaluator | BART-based stance detector (MultiNLI-trained, from Lewis et al. 2019) for generative-model responses; validated against 110 human-annotated responses, 0.97 accuracy, Fleiss' kappa 0.85. Not an LLM judge. |
| Statistical method | t-tests (p<0.05) for downstream-task performance differences between partisan-pretrained and vanilla models; descriptive comparison of political-compass coordinate shifts. |
| Observational/causal | **The one locked paper with a genuine controlled intervention**, not just observational correlation: continued-pretraining RoBERTa/GPT-2 on the 6 partisan corpora with everything else held fixed (architecture, downstream fine-tuning data, hyperparameters) isolates the causal effect of pretraining-corpus political lean on both (a) measured political-compass position and (b) downstream fairness - this is the closest any locked paper gets to anatomiae's own D -> W -> B causal ambition, at small scale. |
| Released code | Yes, MIT license - `github.com/BunsenFeng/PoliLean`, 41 stars. |
| Released data | Partisan pretraining corpora built from POLITICS + Reddit/PushShift; exact corpus construction and stance-detector hyperparameters in appendices. |
| Reproducibility | Good for the intervention design (clear corpus construction, controlled variables, code released); PushShift API access has degraded significantly since 2023 (Reddit API changes), a real risk for exact reproduction of the social-media corpora today. |
| Main finding | (1) Pretrained LMs occupy all four political-compass quadrants; BERT-family models more socially conservative than GPT-family, hypothesized to track BookCorpus vs. modern web-text pretraining-data shifts. (2) Continued pretraining on partisan corpora *does* shift measured political leaning in the corpus's direction, but shifts are modest - "hard to alter the inherent bias present in initial pretrained LMs." (3) More pretraining epochs/data on partisan corpora does *not* drive LMs to political extremes (a mild null result against a "hyperpartisan LM" dual-use concern). (4) Downstream effect: left-pretrained RoBERTa performs better on hate speech targeting minority groups (LGBTQ+, Black) and is stricter on right-leaning misinformation sources; right-pretrained RoBERTa shows the mirror pattern - a real, measured fairness asymmetry traceable to pretraining-corpus political lean. |
| Limitations (authors' own, extensive and candid) | Explicitly flags: (1) PCT itself is imperfect - other political-science theories exist, PCT is Western-issue-centric, and PCT has documented criticisms (unclear scoring, libertarian bias, vague statements) - they used it anyway as "a test bed," not an endorsement. (2) Forcing LMs onto one 2-D point is coarse - "being liberal on one issue does not necessarily exclude being conservative on another" - explicitly leaves fine-grained, issue-specific measurement to future work. (3) Generation-based stance scoring vs. forced-choice MC are both flawed in different ways (subjectivity/interpretability tradeoff). (4) Self-flagged U.S.-centric perspective in the Ethics Statement. |
| What anatomiae reuses | **The controlled-pretraining-intervention design is the strongest methodological precedent in the whole locked set for anatomiae's own future custom-pretraining stage (§71)** - a same-architecture, same-hyperparameters, corpus-only-varies design with a real downstream-task fairness outcome, not just a compass-position shift. The pre-/post-Trump temporal-polarization split is a reusable idea for testing whether pretraining-data political intensity (not just direction) shifts measured behavior. Using a validated, human-checked stance detector rather than an unvalidated LLM judge. Explicitly separating "did the compass position shift" (bias measurement) from "did downstream task fairness change" (behavioral consequence) - maps directly onto anatomiae's Formation/Expression/Measurement separation (§73). |
| What anatomiae rejects | **This locked paper's own primary instrument is the Political Compass Test** - directly in tension with anatomiae's own §74 rule ("do not use Political Compass as primary measurement"). The paper's authors themselves candidly list PCT's flaws (Western-centric, contested scoring, "libertarian bias") as limitations, which is exactly why anatomiae should treat this paper as the methodological/causal-design precedent to reuse, while sourcing the actual measurement instrument from Faulborn's theory-grounded scoring (applied to a mixed PC+WVS item bank - see the Faulborn row above, corrected 2026-09-23) or anatomiae's own §50 multidimensional vector instead of raw PCT scoring. Also reject: forcing every model onto a single 2-D point as a final measurement (their own limitation #2, which anatomiae's 7-dimension vector already supersedes); PushShift-based Reddit corpus construction should be re-scoped or substituted given API degradation since 2023 if this design is replicated. |
